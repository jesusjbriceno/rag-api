# Tasks: Historical Ingestion Rebaseline

Implementation tasks for change `historical-ingestion-rebaseline` derived from `proposal.md`, `spec.md`, and `design.md`. The change is evidence-gated: every executable task follows strict TDD (RED → GREEN → TRIANGULATE → REFACTOR), and every tranche of tasks is blocked by the previous tranche's recorded evidence. Single-threaded writes; one work unit at a time; tests stay with the behaviour they verify; no task authorizes deployment, production corpus loading, push, commit, publish, branch/PR/CI creation, or RDD enablement — implementation-only verification (`dotnet test`, SQLite integration tests, Windows filesystem tests, Cloudflare/JWT unit tests, view-model/automation tests for the WPF shell) is the verification bound.

Protected WIP paths are explicit and unchanged throughout every work unit below: `src/Rag.AdminApp/`, `src/Rag.AdminApp.Host/`, the AdminApp `Dockerfile` `admin` target, `compose.coolify.yaml` admin-related work, AdminApp CI workflows, and `src/Rag.Companion/` are read-only references until a Companion-disposition record explicitly authorizes a bounded follow-up. The existing `POST /api/v1/collections/{id}/ingestions:txt` real-time route stays compatible and untouched. PostgreSQL, llama.cpp, content storage, and administrative services stay non-public; no new internal-service endpoint is exposed.

The design keeps WPF as a **provisional** Windows shell; Electron is not selected and is not a precondition. The UI technology may be reconsidered after Gate L only with evidence (accessibility, packaging, operator feedback) — never as a Gate L blocker. No full-corpus target is chosen; the >500 GB corpus is not loaded.

**Historical evidence — prior blocked attempt:** `apply-progress.md` records the original Unit 1 inventory pilot attempt (single unit, ~1,050 minimum authored lines, edit surface limited to Core/Engine + tests) that was blocked by two verified blockers: `Microsoft.Data.Sqlite` not declared under Central Package Management (`Directory.Packages.props`), and a coherent minimum estimate exceeding the 400-authored-line budget. That record is preserved verbatim and is **not modified** by this revision.

**Division of the inventory pilot:** The original single Unit 1 is replaced by three coherent sequential subunits. Unit 1a was completed at ~747 authored lines after the maintainer explicitly accepted a `size:exception` for that unit alone; Units 1b and 1c retain their ≤400-line bounds. Unit 1b does not start before Unit 1a is green; Unit 1c does not start before both Unit 1a and Unit 1b are green; Units 2–14 do not start before Unit 1c is green.
